## Tekoälyn käyttö projektissa

Projektissa on hyödynnetty Claude-tekoälyä seuraavissa toiminnoissa:

- Robot Framework -koodin parantaminen ja kehittäminen
- Koodikommenttien selkeyttäminen ja asiallisemmaksi muokkaaminen
- Koodin modernisointi ja parhaiden käytäntöjen soveltaminen
- Virheiden diagnosointi ja syvällinen analyysi toimimattomasta koodista
